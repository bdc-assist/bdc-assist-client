Tool view

One look for every tool's object, so a third tool (a cohort, a variable table, an export) doesn't invent its own. In the answer: the same card for every object, a header row (icon, name, Edited, one open button) and a summary line; the graph shows its inline view under the same two rows, so opening the tool reads as the panel shrinking to its header. In the tool view: the same name, Edited and summary in the header, then Undo/Redo, the tool's own action (Open form; none for the graph yet), Close. Edited opens a small menu with Reset to original, for every tool. The chat shows the hint only before the first message.

Chat to the right keeps the tool's chat visually apart from the conversation's composer (with chat below, two composers sit side by side at the bottom), and gives the graph its full height, and the chat shows every message. When the tool is under 600px wide (320 for the object, 280 for the chat) the chat drops below anyway. Chat below keeps the object full width and shows the last exchange with earlier ones folded. Either way the graph's details are a short strip stacked under the graph (not a column beside it, as in the client now), so with the chat below it's graph, details, chat. Each card's button opens its tool, and is gone while the tool is open.
